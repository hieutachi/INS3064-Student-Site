  1. 01Before class · suggested 15–25 min

    Prepare one small step

    Review your own local forms, prepared statements, output escaping, and authentication. List the inputs and state-changing actions that need protection.

    Read the chapter
  2. 02In class · 3 hours scheduled

    Follow, predict, then try

    Map each defensive control to its purpose: parameter binding, context-appropriate output escaping, CSRF verification, password hashing, and upload validation.

    Open the lecture deck
  3. 03After class · suggested 30–60 min

    Make the pattern yours

    Review only your own local application. Verify that state-changing forms require valid CSRF tokens, passwords are hashed, and untrusted output is escaped; record the fixes.

    Return to practice examples
  4. 04Homework · The assignment

    Security Methods

    Security audit — CSRF, XSS, SQL injection fixes plus a security checklist.

    Perform a comprehensive security audit and hardening of your Product Management System. This assignment focuses on identifying and mitigating the most common web application vulnerabilities — CSRF, XSS, SQL injection, insecure file uploads, and brute-force attacks. You will also document every security measure in a checklist. Treat this as a real-world security review of your own codebase.

    Due: Sunday 23:59 | Files: product_app/, SECURITY_CHECKLIST.md
