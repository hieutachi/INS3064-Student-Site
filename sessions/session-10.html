  1. 01Before class · suggested 15–25 min

    Prepare one small step

    Start Apache and MySQL and load the chapter's test database. Review SQL placeholders and keep local credentials out of shared code.

    Read the chapter
  2. 02In class · 3 hours scheduled

    Follow, predict, then try

    Trace the PDO connection, prepare, execute, and fetch steps. Bind user-supplied values instead of concatenating them into SQL.

    Open the lecture deck
  3. 03After class · suggested 30–60 min

    Make the pattern yours

    Make events.php display live MySQL rows for the weekly checkpoint. Try an empty result and a failed connection; keep the response understandable and output escaped.

This assignment brings together database design, SQL queries, PHP database connectivity (PDO), form handling, session management, and basic web UI into a single cohesive project.

    Work the task

    1. Read the sheet first — Overview, Requirements, and the grading rubric are the contract you are marked against.

    3. Test against every functional and technical requirement, then use the sheet's Tips & Resources when stuck.

    Submit on LMS

    1. Part 1 — Code ZIP. Zip the finished file/folder using the filename specified in the homework sheet and upload it to the LMS assignment.

    3. Deadline: Sunday 23:59. Late work is marked until Monday 23:59 at −20%; after that it scores 0. Test your link in an incognito window first.
