  1. 01Before class · suggested 15–25 min

    Prepare one small step

    Start MySQL in XAMPP and open phpMyAdmin. Review the difference between a database, a table, a row, and a column.

    Read the chapter
  2. 02In class · 3 hours scheduled

    Follow, predict, then try

    Create tables in a practice database. Explain each column type and primary key, then inspect the structure in phpMyAdmin.

    Open the lecture deck
  3. 03After class · suggested 30–60 min

    Make the pattern yours

    Create the first three Club Hub tables from the weekly plan. Export a schema copy and check that your saved SQL recreates those tables in a separate practice database.

    Return to practice examples
  4. 04Homework · The assignment

    Introduction to MySQL

    University database — design 6 tables in SQL and seed them with data.

    In this assignment you will design and create a relational database schema for a University Course Registration System using MySQL. You will practice database design concepts including tables, primary keys, foreign keys, data types, constraints, and inserting sample data. The deliverable is a single .sql file that, when executed, creates the entire database from scratch.

    Due: Sunday 23:59 | File: university_db.sql

    Open homework sheet
  5. 05Homework · How to do it

    Work the task

    1. Read the sheet first — Overview, Requirements, and the grading rubric are the contract you are marked against.
    2. Build the task in your XAMPP htdocs folder until it runs at http://localhost/… without errors.
    3. Test against every functional and technical requirement, then use the sheet's Tips & Resources when stuck.
    4. Rehearse the Video Checklist — What to Show at the bottom of the sheet; it is exactly what you will record.

    3. Deadline: Sunday 23:59; the exact deadline, repository naming, Sheet URL, and access settings come from Telegram. Test both links before submitting.
