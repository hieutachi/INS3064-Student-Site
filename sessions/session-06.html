  4. 04Homework · The assignment

    Database Design

    Bookstore database — ERD, 3NF design, full schema and sample data.

    Design a complete relational database for an Online Bookstore system. You will create an Entity-Relationship Diagram (ERD), normalize your design to Third Normal Form (3NF), write the full SQL schema with constraints, and populate the database with realistic sample data. This assignment builds the foundation for Homework 7 (Advanced SQL queries).

    Due: Sunday 23:59 via LMS | Files: bookstore_erd.md, bookstore_db.sql

    Work the task

    1. Read the sheet first — Overview, Requirements, and the grading rubric are the contract you are marked against.

    3. Test against every functional and technical requirement, then use the sheet's Tips & Resources when stuck.
    4. Rehearse the Video Checklist — What to Show at the bottom of the sheet; it is exactly what you will record.

    Submit on LMS

    1. Part 1 — Code ZIP. Zip the finished file/folder using the filename specified in the homework sheet and upload it to the LMS assignment.

    3. Deadline: Sunday 23:59. Late work is marked until Monday 23:59 at −20%; after that it scores 0. Test your link in an incognito window first.
