14 graded sheets

Weekly homework

Fourteen graded sheets — build the task, record a short OBS demo, submit ZIP + YouTube link on LMS.

Homework is the graded half of the course: every week you build a small task from the session you just covered, then prove it is done and it is yours. Homework is set at the end of each session and is due Sunday 23:59 of the following week on LMS. (Week 8 is the midterm — no graded homework.)

Each week you submit two things on LMS:

  1. Part 1 — the code ZIP. Zip the finished project folder and upload it to the LMS assignment.
  2. Part 2 — the video link. Record a 1–2 minute screen-and-voice demo with OBS Studio, upload it to your own YouTube channel as Unlisted, add it to your semester playlist INS3064 — Homework — <Your Full Name>, and paste the video (or playlist) URL into the LMS "Video Link" field. Upload the link — never the video file.

Every sheet ends with a Video Checklist — What to Show: the exact items to demonstrate in your recording, so the grader can see the homework works and the code is yours. Test your YouTube link in an incognito window before submitting — Private links cannot be graded.
