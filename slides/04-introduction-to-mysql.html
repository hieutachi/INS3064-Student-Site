Theory1.1 Definition

1What is database?

Database (Cơ sở dữ liệu) = Organized storage place for data, can retrieve, manage and update.

Real-life Analogy

Database is like an office filing cabinet:

  • Database = Filing cabinet
  • Table = Drawer
  • Row = One file
  • Column = Information items on the file

Theory1.2 Why Do We Need Database?

1What is database?

ProblemWithout DBWith DB
StorageText files, hard to manageStructured, easy to manage
SearchSlow, must read allFast with index
SecurityHard to controlHas users, permissions

1.3What is MySQL?

MySQL = Most popular Relational Database Management System (RDBMS).

Features:

  • ✅ Free, open source
  • ✅ Fast, stable
  • ✅ Easy to use
  • ✅ Great integration with PHP
  • ✅ Large community

Who uses MySQL?

  • Facebook, Twitter, YouTube, Wikipedia, WordPress

Theory3.2 Via SQL

DROP DATABASE removes everything inside it

Keep ins3064_db — Section 4 creates a table in it. Only run this when you genuinely want the database and all its tables gone.

Naming Rules

  • Use lowercase
  • No spaces
  • Use underscore: my_database
  • Meaningful: shop_db, blog_db
