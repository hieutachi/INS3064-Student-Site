Course Code: INS3064
Instructor: M.Sc. Hieu Ta Chi (Tạ Chí Hiếu)
Host Department: Applied Sciences Department - International School - VNU (IS-VNU)
Designed for university students, with step-by-step guidance, real-world examples, and easy-to-understand code samples.

🎯Material objectives#

This material helps students:

  • Master web design and programming with PHP & MySQL.
  • Build dynamic websites from basic to advanced.
  • Design and manage MySQL databases.
  • Implement security mechanisms: SQL Injection, XSS Prevention.
  • Learn in a "hands-on" style with real examples and clear code comments.
  • Complete a real-world Web Application project with full features.

🧩Material structure#

The curriculum consists of 4 major parts and 15 sessions:

🟦Part 1 — PHP foundation (Sessions 1-3)#

Designed for beginners, including:

  1. Introduction to PHP — Getting familiar with PHP, basic syntax
  2. Programming PHP — Variables, data types, functions, arrays
  3. Dynamic Websites — Form handling, GET/POST

Each session includes:

  • Detailed explanations with real-life examples
  • Code samples with line-by-line comments
  • Comparisons with other languages (if applicable)
  • Small exercises for immediate practice
  • End-of-session worksheets

🟩Part 2 — MySQL & database (Sessions 4-7)#

Core database section:

  1. Introduction to MySQL — Installation, configuration, phpMyAdmin
  2. Introduction to SQL — SELECT, INSERT, UPDATE, DELETE
  3. Database Design — Normalization, Relationships
  4. Advanced SQL — Joins, Subqueries, Stored Procedures

Each session integrates into a real project, students gradually build:

  • Database for web application
  • Related tables
  • Complex queries

🟨Part 3 — integration & advanced (Sessions 9-12)#

The most important part for building complete applications:

  1. Error Handling — Try-catch, Exception, Debug
  2. PHP + MySQL — Connection, PDO, CRUD Operations
  3. Programming Techniques — OOP, MVC Pattern
  4. Web Application Development — Mini Project

Students will build:

  • Complete CRUD application
  • Secure database connection
  • Well-structured code

🟧Part 4 — security & jQuery (Sessions 13-15)#

  1. Cookies & Sessions — User Authentication
  2. Security Methods — SQL Injection, XSS, CSRF Prevention
  3. jQuery Introduction — DOM Manipulation, AJAX

This section helps students:

  • Manage login sessions
  • Secure web applications
  • Enhance interactivity with jQuery

📝Review session#

  1. Review & Midterm — Review and midterm exam

👨‍🏫Presentation style#

The instructor will:

  • Avoid difficult terminology or explain immediately when it appears.
  • Illustrate with real-life examples for immediate understanding.
  • Use short code with clear line-by-line comments.
  • Compare with other frameworks/languages to show advantages.
  • Create a "each session is a practice session" feeling.
  • Always connect with the ongoing project.

📌Effective learning methods#

Students should:

  1. Read theory slowly and follow examples — Don't skip any code.
  2. Type all code, don't copy/paste — The only way to remember long-term.
  3. Run code immediately after each section — See results, fix errors, experiment.
  4. Do small exercises after each section — Reinforce knowledge.
  5. Complete worksheets — Check understanding.
  6. Integrate into project — Learn alongside real project.
  7. Ask when you don't understand — Don't leave knowledge gaps.

🎓Prerequisite knowledge#

You need to know:

  • Basic HTML: Tags, webpage structure
  • Basic CSS: Styling, layout
  • Logical thinking: Basic algorithms

If not solid:

  • Review basic HTML/CSS
  • Review programming logic

💡Advice from instructor#

✅Do:#

  • Type code instead of copy/paste
  • Run code after small changes
  • Read error messages carefully
  • Do exercises immediately after each section
  • Ask when you don't understand
  • Participate in practice sessions

❌Don't:#

  • Skip theory, jump straight to code
  • Copy code without understanding
  • Do multiple sessions at once
  • Skip exercises
  • Study alone without discussion
  • Wait until the end to do project
